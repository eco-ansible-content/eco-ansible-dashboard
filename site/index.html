How to read these results

Actions: passing means every monitored GitHub Actions workflow succeeded on the current default-branch commit. Missing, skipped, or cancelled runs are unknown. External CI results are not included in this status.

Core: supported versions come from meta/runtime.yml. CI tested versions are configured coverage from public CI definitions, including Azure Pipelines and reusable workflows; they do not imply a successful run. Open repository details for source links.

New issues: open issues created in the past seven days. Needs triage means a needs-triage label, or no assignee/comments and no triaged label. This is a configurable signal of likely pending work, not proof that nobody has read the issue.
